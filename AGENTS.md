# MetricPilot working rules

The owner authorized AI-assisted implementation. Preserve that attribution; do not imply the owner independently hand-authored or already understands every component.

Keep deterministic numerical/controller checks distinct from real model benchmarks. Do not call mock action-selection tests evidence of live LLM quality. The public UI must state synthetic data and actual execution mode.

Only approved analytical tools may access DuckDB. Never execute user/model SQL or shell code. Credentials stay in ignored local configuration or a provider secret store. Paid calls need a confirmed budget and a working stop condition. Public live mode requires durable shared quotas; do not disable that requirement to make a demo look complete.

Read pinned package documentation when uncertain. Run the relevant analytical/API checks, frontend typecheck/build and browser workflows before claiming completion. Report unverified deployment and model access explicitly.
